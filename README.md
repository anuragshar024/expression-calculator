# Expression Calculator 🧮

A simple Expression Calculator designed to perform basic mathematical operations and evaluate expressions.

🚀 Features

- Performs basic arithmetic operations
- Supports addition, subtraction, multiplication and division
- Takes mathematical expressions as input
- Displays the calculated result
- Simple and beginner-friendly project

🛠️ Technology Used

- C Programming Language

🧮 Example

Input: 10 + 5 * 2

Output: 20

🎯 Purpose

This project was created to practice C programming, operators, expressions, and basic programming logic.
